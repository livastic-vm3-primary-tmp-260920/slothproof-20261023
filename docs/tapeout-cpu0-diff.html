Why this scope is intentionally narrow

What the report can say

For two explicit block heights, it can enumerate selected field changes and unchanged fields with source pins, return structured machine-readable JSON, and distinguish X Layer data from Base USDC payment metadata.

What it cannot say

It does not certify contract solvency, audit every intermediate block, inspect all assets, prove a vulnerability, forecast token prices, guarantee a current chain state, or guarantee a merchant payment will settle. Unavailable RPC should fail as unavailable rather than request money for broken data.
